Expense Tracker — Backend

Backend service for the Expense Tracker application, developed as part of a Software Quality Engineering (SQE) project.

The repository provides the server-side APIs, data handling, automated tests, and CI/CD configuration required to support the Expense Tracker application.

🚀 Getting Started

Install dependencies:

npm install


Run the test suite:

npm test


Start the application using the configured Node.js/Vercel setup.

This backend was developed to support the Expense Tracker SQE project, with an emphasis on API development, software testing, continuous integration, and reliable frontend–backend communication.
